# The Kingverse Media Library

This local library is separate from the existing website and Explorer. It does not change their images.

- `fallbacks/book.svg`, `fallbacks/screen.svg`: original neutral geometric placeholders generated by `scripts/build_media_library.cjs`, not official covers or posters. SVG remains sharp at responsive sizes without raster variants.
- `covers/edn-000001/…`: reserved for a specifically authorized edition image and its responsive variants.
- `posters/adp-000001/…`: reserved for a specifically authorized production image and its variants.

There are currently zero cleared local covers/posters. No external image is downloaded by any ordinary build or test. Existing URL metadata does not authorize downloading, resizing or redistribution. Do not suppress Referer, proxy a refused image or treat a visual review as a licence.

`data/media/library.json` is generated from the preserved canonical artworks, provenance policies and the reviewed input `data/media/permissions.json`. The latter currently has no decisions. A future decision needs the exact artwork ID, owner ID and original URL; rights holder, explicit permission evidence, licence and conditions; technical verification and its date; an allowed local path and variant paths; dimensions, MIME type, byte counts and SHA-256 hashes. Evidence must establish the actual local use, including any resizing or format conversion. A field set to “allowed” is not itself proof. No account, paid package or API is necessary.

Regenerate with `npm run build:media` and `npm run build:readiness`. Validate with `npm run validate:readiness`. The validators reject incomplete permission gates, wrong ownership, unknown files, symlinks, paths outside the controlled directory and mismatched integrity/aspect metadata. Hash validation does not independently establish copyright or visually identify an image; real artwork approval also requires the documented source, title/language, visual and decoding checks. No new artwork went through such an approval in Batch 06.

Collection-only stories do not get a fabricated independent cover. The selector follows registered membership and edition IDs, marks provisional memberships, uses the existing registered default rather than inventing contents order, and links to the collection. Missing edition covers and posters are counted separately from stories that do not need their own cover. An EN page does not silently substitute a Dutch image; an EN fallback on NL is explicitly marked.
